==================================================
          AstrBot 影视搜索插件 使用说明
==================================================
插件名称：film_search
显示名称：影视搜索助手
版本号：1.0.0
支持 AstrBot 版本：>= 4.5.7
API 来源：https://api-v2.yuafeng.cn
==================================================

一、插件功能
--------------------------------------------------
本插件提供两种影视搜索方式，满足不同使用场景：
1. 【LLM 自动调用】直接在对话中说出搜索需求（如“帮我搜一下变形金刚3”、“我想看哪吒”），
   LLM 会自动识别意图调用搜索工具，返回完整的影视信息和播放链接。
2. 【手动指令】通过固定指令快速搜索、查看详情、获取播放地址，响应速度更快。

核心特性：
✅ 支持按片名搜索影视，返回豆瓣评分、简介、导演、演员等信息
✅ 自动返回 m3u8 流媒体链接和 mp4 下载链接
✅ 支持按搜索结果序号或影视ID查询详情
✅ 自动缓存最近一次搜索结果，无需重复搜索即可查询详情/播放链接
✅ 支持自定义 API Key，提升调用额度
✅ 支持配置单次搜索最大返回条数，避免消息过长

==================================================

二、安装步骤
--------------------------------------------------
1. 在插件市场搜索film_search直接安装或者到https://github.com/2845075734-ai/astrbot_plugin_film_search 下载安装
2. 将以下三个文件放入该文件夹：
   - main.py（插件主代码）
   - metadata.yaml（插件元数据）
   - _conf_schema.json（配置文件Schema）
3. 打开 AstrBot WebUI，进入「插件管理」页面
4. 找到「影视搜索助手」插件，点击「重载插件」
5. 确认日志出现 [film_search] ✅ 配置读取成功 提示，即安装完成

==================================================

三、配置说明
--------------------------------------------------
安装完成后，在插件管理页点击「配置」按钮，可填写以下配置项：
1. API 密钥 (apikey)
   - 必填（免费额度可能受限，建议填写）
   - 获取地址：https://api-v2.yuafeng.cn（注册后即可获取免费Key）
   - 填写后点击保存，再重载插件即可生效
2. 单次搜索最大返回条数 (max_results)
   - 默认值：0（表示不限制，返回全部结果）
   - 如果担心消息过长，可设置为 10/20 等数字，限制单次返回的影视条目数量

==================================================

四、使用方法
--------------------------------------------------
（一）LLM 自动调用（无需记指令）
直接在对话中说出你的需求，例如：
- "帮我搜一下哪吒之魔童闹海"
- "我想看长安三万里，有没有播放链接？"
- "搜索一下2024年的喜剧电影"
LLM 会自动调用搜索工具，返回完整的影视信息和播放地址。

（二）手动指令（快速响应）
指令组前缀：/film
--------------------------------------------------
1. 搜索影视
   指令：/film search <片名>
   示例：/film search 变形金刚3
   功能：搜索影视资源，返回带封面的结果列表，自动缓存搜索结果
   提示：搜索后会生成序号，可直接用序号查询详情/播放链接

2. 查看详情
   指令：/film detail <序号/ID>
   示例：/film detail 1  或  /film detail 101261
   功能：查看影视的详细信息，包括上映时间、地区、导演、演员、豆瓣评分、简介等
   说明：优先使用最近一次搜索的序号，也可直接输入影视ID查询

3. 获取播放链接
   指令：/film play <序号/ID>
   示例：/film play 1  或  /film play 101261
   功能：返回该影视的所有播放链接，包含 m3u8 流媒体地址和 mp4 下载地址
   说明：优先使用最近一次搜索的序号，也可直接输入影视ID查询

4. 查看帮助
   指令：/film help
   功能：查看插件使用说明

（三）调试指令（仅管理员可用）
指令：/filmdebug
功能：查看插件配置读取状态、API Key 是否生效、测试 API 调用是否正常
适用场景：遇到搜索失败、读不到Key等问题时使用，便于排查故障

五、常见问题
--------------------------------------------------
1. 搜索时提示「缺少必要的apikey参数」
   - 原因：未配置 API Key 或配置未生效
   - 解决方法：
     ① 前往 https://api-v2.yuafeng.cn 注册获取 API Key
     ② 在插件配置页填入 Key 并保存
     ③ 重载插件，确认日志出现 ✅ 配置读取成功 提示
     ④ 确认插件文件夹名为 film_search（不要有空格、大小写错误）

2. 搜索不到结果
   - 确认 API Key 有效（可在浏览器访问 https://api-v2.yuafeng.cn/API/filmSearch.php?msg=哪吒&apikey=你的Key 测试）
   - 尝试更换关键词，部分小众影视可能未被收录

3. 消息太长被截断
   - 在插件配置页将「单次搜索最大返回条数」设置为 0（不限制）
   - 或根据平台消息长度限制设置为合适的数字（如10、20）

4. 序号查询失效
   - 搜索结果序号仅对当前用户最近一次搜索有效，若重新搜索了其他片名，旧序号会失效
   - 可直接输入影视ID查询，不会失效

==================================================

六、注意事项
--------------------------------------------------
1. 播放链接来自第三方接口，仅供个人学习研究使用，请勿用于商业用途
2. 部分平台对消息长度有限制，若返回内容过长可能被平台截断，可调整 max_results 配置
3. 插件配置修改后需要重载插件才能生效
4. 若遇到问题，可先使用 /filmdebug 指令查看调试信息，便于排查故障
